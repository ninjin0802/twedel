# twedel

自分のX（旧Twitter）のポストを、条件を指定してまとめて削除できるWindowsアプリです。

難しい設定は基本的に不要です。アプリを起動すると専用のChromeが開き、Xへログインすることで自分のポストを取得できます。

## 動作環境・必要なもの

| 項目 | 必要条件 |
|---|---|
| OS | Windows 10／11（64ビット） |
| CPU | IntelまたはAMDの64ビットCPU |
| メモリ | 4GB以上（8GB以上を推奨） |
| 空き容量 | 500MB以上 |
| ブラウザ | Google Chrome最新版 |
| ネット接続 | Xへの接続とアプリの更新に必要 |
| アカウント | 削除対象となるXアカウント |

一般利用者がNode.js、npm、Git、開発ツールをインストールする必要はありません。アプリの実行に必要なElectron、Node.jsランタイム、その他のライブラリはWindows版インストーラーに同梱されています。

Google Chromeは、Xへのログインと認証情報の安全な取得に使用します。Microsoft EdgeやFirefoxだけがインストールされた環境では、自動取得機能を利用できません。

## できること

- 自分のポスト、返信、リポスト、いいねを取得
- 複数のXアカウントを保存してワンクリックで切り替え
- 保存したアカウントを個別に削除、またはアカウント設定を一括リセット
- 日付、キーワード、種類などで削除対象を絞り込み
- 残したいポストをアカウント別の除外リストで保護（固定ポストはライブ取得時に自動保護）
- 削除前に対象件数と内容を確認
- 複数のポストをまとめて削除
- 処理を中断して、あとから続きから再開
- アプリ内から最新版へ自動更新
- バージョン情報からOFUSEを通じて任意で開発を支援
- 削除したポストの本文を履歴ログに残さない
- 専用Chrome終了後に不要なキャッシュを自動整理

## 使い方

1. インストーラーをダウンロードして実行します。
2. twedelを起動します。
3. 専用のChromeが開いたら、Xへログインします。
4. 別のアカウントも使う場合は「別のアカウントを追加」からログインします。
5. アカウントカードで対象アカウントを確認し、「取得」を押します。
6. 日付や種類などの条件を指定します。
7. 削除するポストを選択します。
8. 残したいポストは一覧右端の鍵ボタンで保護します。
9. 確認画面の内容を確認して削除を実行します。

詳しい操作は[使い方ガイド](docs/USER_GUIDE.md)をご覧ください。

## 必ず確認してください

> [!CAUTION]
> 削除したポストは元に戻せません。必要なデータは、事前にXの「データのアーカイブをダウンロード」から保存してください。

> [!WARNING]
> このアプリはXの公開されていない仕組みを利用します。X側の変更によって突然動作しなくなる場合や、アカウントの再認証を求められる場合があります。利用は自己責任で行ってください。

## データとプライバシー

詳細は[プライバシーポリシー](PRIVACY.md)をご覧ください。

- 認証情報は利用中のPC内に保存されます。
- 保存済みアカウントの認証情報は画面やローカルAPIから読み戻せず、切り替えには内部IDだけを使用します。
- 「twedelから削除」と「アカウント設定をリセット」は端末内の保存情報だけを消します。Xのアカウント自体は削除しません。
- アカウントを切り替えると、別アカウントへの誤操作を防ぐため取得一覧と選択状態がリセットされます。
- 保護したポストIDはXアカウント別に端末内へ保存され、保護解除するまで選択・削除対象から除外されます。
- Xの認証情報を開発者へ送信する機能はありません。
- 削除したポストの本文や削除結果は履歴ログへ保存しません。
- 中断から再開するための一時データは、処理完了後に削除されます。
- 通信先は基本的にXとGitHub Releases（更新確認・ダウンロード）です。
- 「開発を支援する」を押した場合だけ、標準ブラウザで[OFUSEの支援ページ](https://ofuse.me/ninjin)を開きます。支援は任意で、支援の有無による機能差はありません。
- ChromeのログインCookieは維持し、HTTPキャッシュ・Service Workerキャッシュ・GPUキャッシュだけを整理します。

## セキュリティ

- ローカルAPIは`127.0.0.1`だけで動作し、同じネットワークの別端末からアクセスできません。
- 外部サイトからのAPI操作、不正なウィンドウ表示、外部URLへの遷移を拒否します。
- Electronではsandboxとcontext isolationを有効にし、画面側からNode.jsを直接操作できない構成です。
- 認証情報はAPIから読み戻せず、エラーや診断情報にも生の値を含めません。
- Electronを含む全依存パッケージは、リリース時に既知の脆弱性を確認します。

詳しい設計、利用者向け注意事項、非公開の脆弱性報告方法は[セキュリティポリシー](SECURITY.md)をご覧ください。

## 自動アップデート

新しいバージョンがある場合、アプリ内にバージョン番号と更新内容が表示されます。

「ダウンロードして自動更新」を押すと、ダウンロード状況がプログレスバーで表示されます。完了後はユーザー操作なしで更新され、アプリが自動的に再起動します。

## 困ったとき

- Chromeからログイン情報を取得できない
- ポストを取得できない
- 401、403、404などのエラーが表示される
- 自動更新に失敗する
- かなり古いポストやリポストがライブ取得に出てこない

上記については[トラブルシューティング](docs/TROUBLESHOOTING.md)をご覧ください。

Xがライブのタイムラインへ返さない古いデータは、XからダウンロードしたアーカイブZIPを「その他の取得方法」から読み込むと取得できます。

不具合を報告する場合は、[GitHub Issues](https://github.com/ninjin0802/twedel/issues)を利用してください。認証情報やCookieは絶対に貼り付けないでください。
