## 更新内容

- ログインCookieとNetwork情報を維持したまま、専用Chromeの不要キャッシュを終了後に自動整理
- HTTP Cache、Code Cache、Service Worker CacheStorage、GPU Cache、BrowserMetricsを安全な対象に限定
- 取得結果を画面へ返した直後に完了ジョブから解放し、大量取得時のメモリ二重保持を解消
- 完了ジョブへ5分の有効期限を設定し、受け取られなかった結果も自動整理
- 成功したタイムライン取得経路をアカウントID別に記憶し、複数アカウント切り替え後の不要な再探索を削減
- キーワード絞り込みで同じ検索語を行ごとに小文字変換していた重複計算を削減
