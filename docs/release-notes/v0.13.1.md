# twedel v0.13.1

## 日本語

### 英語表示の翻訳漏れを修正

- 接続設定、詳細設定、バージョン情報に残っていた日本語を英訳しました。
- 過去の更新履歴を英語モードで表示できるようにしました。
- 英語モードの全ページと初回同意画面を自動走査し、日本語が残らないことを確認しました。
- 未知の動的メッセージでも日本語と英語が混在しない安全処理を追加しました。

## English

### Completed the English translation

- Translated remaining Japanese text in connection settings, advanced settings, and About.
- Added an English presentation for earlier release history.
- Automatically scanned every page and the first-run consent screen to verify that no Japanese text remains in English mode.
- Added a safeguard that prevents mixed Japanese/English output from unknown dynamic messages.
