# twedel v0.13.0

## 日本語

### 日本語・英語の表示切り替え

- アプリ画面を日本語と英語で切り替えられるようになりました。
- 初回起動時はOS・ブラウザの言語から表示言語を自動選択します。
- 選択した言語は端末内に保存され、次回起動時にも引き継がれます。
- READMEとリリースノートを日本語・英語の両方で提供します。

## English

### Japanese and English interface

- Added a language selector for switching the app between Japanese and English.
- The initial language follows the OS or browser language.
- The selected language is saved locally and restored on the next launch.
- The README and release notes are now available in both Japanese and English.
