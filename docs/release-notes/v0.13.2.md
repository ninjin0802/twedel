# twedel v0.13.2

## 日本語

### 英語表示の動的アカウント欄を修正

- 保存済みユーザー名を含む文全体が `English translation unavailable.` に置き換わる問題を修正しました。
- 不適切な代替エラー文を撤去し、アカウント状態・切り替え・追加・リセットの文言を正しく英訳しました。
- 長い文章と複合語を先に翻訳し、`リPost`のような日英混在を防止しました。
- 保存済みアカウントを模擬して全ページを検査し、日本語と代替エラー文が残らないことを確認しました。

## English

### Fixed dynamic account details in English mode

- Fixed entire strings containing a saved username being replaced with `English translation unavailable.`.
- Removed the faulty fallback and properly translated account status, switching, adding, and reset controls.
- Prioritized full phrases and compound words to prevent mixed output such as `リPost`.
- Scanned every page with a simulated saved account and verified that neither Japanese nor fallback error text remains.
