# twedel v0.12.0

## 更新内容

- Windows DPAPI（Electron `safeStorage`）で保存する `auth_token` と `ct0` を暗号化
- 既存バージョンで保存された平文Cookieを、初回読み込み時に暗号化形式へ自動移行
- Electronが起動ごとに生成する秘密トークンで、画面とローカルHTTP API間の通信を認証
- 認証Cookieの登録経路をElectron IPCへ移し、localhost HTTP本文への送信を廃止
- 配布版のReact画面からの通常API・進捗ストリームをすべてElectron IPC経由へ移行
- 初回起動時に、非公式APIの利用・Xの仕様変更・アカウント制限や凍結リスクへの同意画面を追加
- 同意後もアプリ内にリスク表示を常設
- READMEへ同じ注意事項と暗号化方式を明記

> twedelはX公式APIではなく内部APIを使用します。Xの利用規約への抵触、仕様変更による停止、アクセス制限、アカウント凍結などの可能性があります。利用はご自身の判断と責任で行ってください。
