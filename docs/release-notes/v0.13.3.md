# twedel v0.13.3

## 日本語

### アプリ内バージョン表示を修正

- バックエンドが古い固定値 `0.12.0` を返し、画面の新しいバージョンを上書きする問題を修正しました。
- Electron実行ファイルの実バージョンをバックエンド経由で画面へ渡すようにしました。
- package、exe、サイドバー、About、更新画面がすべて `0.13.3` で一致します。

## English

### Fixed the in-app version display

- Fixed the backend returning the stale hard-coded value `0.12.0` and overriding the current UI version.
- The Electron executable now passes its actual version through the backend to the UI.
- Package, executable, sidebar, About, and update screen versions now all match `0.13.3`.

## インストール / Installation

Download `twedel-Setup-0.13.3.exe` from Assets.
