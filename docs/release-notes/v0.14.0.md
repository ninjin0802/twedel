# twedel v0.14.0

## 日本語

### Linux（deb）版を追加

- Linux向けの `.deb` パッケージを追加しました。
- Linuxでは認証情報をシステムのキーリング（Secret Service / gnome-keyring など）で暗号化します。
- アプリアイコンがLinuxのメニューやタスクバーに正しく表示されるようにしました。

### ポストの保護機能を廃止

- ポストごとの保護（鍵ボタン）と、固定ポストの自動保護を削除しました。

### その他

- 依存パッケージを更新し、既知の脆弱性を解消しました。

## English

### Added a Linux (deb) build

- Added a `.deb` package for Linux.
- On Linux, credentials are encrypted with the system keyring (Secret Service / gnome-keyring, etc.).
- The app icon now appears correctly in Linux menus and task bars.

### Removed post protection

- Removed per-post protection (the lock button) and automatic protection of pinned posts.

### Other

- Updated dependencies and resolved known vulnerabilities.

## インストール / Installation

Linux: Download `twedel_0.14.0_amd64.deb` from Assets and install it with `sudo apt install ./twedel_0.14.0_amd64.deb`.

> [!NOTE]
> このリリースにはWindowsインストーラーは含まれていません。Windowsでは v0.13.3 をご利用ください。
> This release does not include a Windows installer. Windows users should keep using v0.13.3.
