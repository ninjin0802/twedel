# twedel 使い方ガイド

[READMEへ戻る](../README.md)

## 必要なもの

- Windows 10またはWindows 11（64ビット）
- Google Chrome最新版
- インターネット接続
- 削除対象となるXアカウント
- 500MB以上の空き容量

Node.js、npm、Gitなどの開発ツールは不要です。必要な実行環境はインストーラーに含まれています。

## 1. インストール

1. [最新のReleaseページ](https://github.com/ninjin0802/twedel/releases/latest)を開きます。
2. 「Assets」にある`twedel-Setup-バージョン.exe`をダウンロードします。
3. ダウンロードしたファイルを実行し、画面に従ってインストールします。
4. twedelを起動します。

## 2. Xへ接続

保存済みの接続情報がない場合は、起動時に専用のChromeが自動で開きます。

1. 開いたChromeでXへログインします。
2. 認証情報の取得が完了するまで画面を閉じずに待ちます。
3. 取得が完了するとChromeは自動的に閉じます。
4. twedelに自分のアカウント名が表示されたことを確認します。

このChromeはtwedel専用です。普段使用しているChromeのプロフィールには影響しません。ログイン情報を手動で入力する方法は、ハンバーガーメニューの詳細設定から利用できます。

## 3. ポストを取得

通常は「自分のポスト」を選択し、取得ボタンを押します。自分が付けた「いいね」を対象にしたい場合は「いいね」へ切り替えます。

より古いポストを確実に扱いたい場合は、Xから取得したアーカイブZIPも利用できます。アーカイブでは正確ないいね数・リポスト数を取得できないため、反応数による絞り込みは使用できません。

## 4. 削除対象を絞り込む

取得したデータは、次の条件で絞り込めます。

- 投稿日
- キーワード
- 通常ポスト、返信、リポスト
- メディアの有無
- いいね数、リポスト数（ライブ取得のみ）

条件を設定したあと、一覧から削除したいポストを選択します。

## 5. 削除を実行

1. 「削除」を押します。
2. 確認画面で対象件数と内訳を確認します。
3. 問題がなければ実行します。

削除中はアプリと通信に使用しているChromeを終了しないでください。Xの利用制限に達した場合は自動的に待機し、可能になった時点で再開します。

リポストは元の投稿を削除するのではなく、自分のリポストを取り消します。元の投稿者のポストは残ります。

## 6. 中断と再開

処理は途中で中断できます。未処理の対象がある場合、次回起動時に再開案内が表示されます。すでに削除済みの対象へ再度削除を試みることはありません。

処理が完了すると対象は一覧から取り除かれ、一時的な再開データも削除されます。

## 7. アプリを更新

ハンバーガーメニューから「バージョン情報」を開き、「更新を確認」を押します。

最新版がある場合は、バージョン番号と更新内容が表示されます。「ダウンロードして自動更新」を押すと、進捗バーが表示され、ダウンロード・インストール・再起動まで自動で行われます。
